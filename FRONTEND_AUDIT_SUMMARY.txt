AUTHENTICATION FLOW
================================================================================

LOGIN ROUTE: /login

DEMO CREDENTIALS:
  Email:    admin@example.com
  Password: password123

FLOW:
  1. User visits /login
  2. Enters credentials
  3. Credentials sent to http://localhost:3000/api/v1/auth/login
  4. Backend validates and returns JWT tokens
  5. Tokens stored in localStorage
  6. User redirected to /dashboard
  7. All protected routes now accessible

LOGOUT:
  1. User clicks logout button in sidebar
  2. Tokens cleared from localStorage
  3. User state cleared from Zustand store
  4. User redirected to /login

PROTECTION:
  ✓ ProtectedRoute component wraps all non-login routes
  ✓ Checks useAuthStore.isAuthenticated
  ✓ Redirects unauthenticated users to /login
  ✓ Preserves JWT tokens in localStorage
